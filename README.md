# LeetCode Practice

## จุดประสงค์
ฝึกแก้โจทย์ LeetCode ด้วย Python เพื่อเตรียมสัมภาษณ์งาน โดยแยกโฟลเดอร์ตามหัวข้อและระดับความยาก

## วิธีจัดเก็บ
- ชื่อโฟลเดอร์หัวข้อใช้ `kebab-case` เช่น `binary-search`
- ภายในหัวข้อแยกตามระดับ เช่น `easy`, `medium`, `hard`
- ไฟล์โจทย์ Python ใช้ `snake_case` เช่น `binary_search.py`
- วางไฟล์โจทย์ไว้ในโฟลเดอร์ระดับความยาก เช่น `binary-search/easy/binary_search.py`

## รูปแบบไฟล์โจทย์
แต่ละไฟล์ควรมี:
1. ชื่อและคำอธิบายโจทย์ภาษาอังกฤษและภาษาไทย
2. ฟังก์ชันเปล่าสำหรับเขียนคำตอบ
3. ตัวอย่าง 4 กรณี พร้อมคำสั่ง `print`

## วิธีเพิ่มหัวข้อหรือโจทย์
1. สร้างโฟลเดอร์หัวข้อด้วยชื่อ `kebab-case`
2. สร้างโฟลเดอร์ระดับความยากภายใน เช่น `easy`
3. สร้างไฟล์โจทย์ด้วยชื่อ `snake_case.py`
4. ใส่เนื้อหาให้ครบตามรูปแบบไฟล์โจทย์ด้านบน
